# Repository map

| Path | Role | Change when |
| --- | --- | --- |
| `AGENTS.md` | Canonical instructions for coding agents | Repository-wide agent rules change |
| `docs/ai/INDEX.md`, `docs/ai/RELEASES.md` | Selective AI documentation index and release guidance | AI document ownership or release procedures change |
| `CLAUDE.md`, `.github/copilot-instructions.md` | Compatibility pointers to the canonical instructions | Agent entry points change |
| `bin/` | Public library and CLI entry point | Public API or CLI behavior changes |
| `parser/` | YAML parsing and BPMNator syntax checking | YAML parsing or validation changes |
| `entities/` | Process model and BPMN domain entities | Data model or BPMN types change |
| `bpmnbuilder/` | BPMN XML generation and graphical layout | BPMN serialization or layout changes |
| `helpers/` | Shared ID and entity helpers | Shared conversion rules change |
| `examples/` | YAML inputs, BPMN output, and rendered examples | Supported syntax or generated output changes |
| `test/` | Node.js regression tests | Bugs or security properties need coverage |
| `dist/` | Generated JavaScript and declarations | Regenerate with `npm run build`; never hand-edit |
| `scripts/` | Release packaging and artifact validation | Package or release invariants change |
| `.github/workflows/` | CI and release automation | Validation or release process changes |
| `package.json`, `package-lock.json` | npm package metadata, scripts, and resolved dependencies | Package, runtime, or dependency changes |
| `CHANGELOG.md` | User-facing history of meaningful changes | Every meaningful code or workflow change |

`package.json` and TypeScript sources are the sources of truth. `dist/` is generated by `tsc`; the npm archive contains the generated runtime and package documentation, not repository tests or examples.
